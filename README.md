# 🌸 Habit Tracker

A clean and simple habit tracker built with HTML, CSS and vanilla JavaScript.

🔗 **Live demo:** https://dev-celia.github.io/habit-tracker/

## Features

- Add new habits
- Mark habits as completed
- Delete habits
- Progress counter and progress bar
- Habits saved in the browser with `localStorage`
- Responsive, minimal design

## Built with

- HTML5
- CSS3
- JavaScript (vanilla)

## Run it locally

1. Clone the repository
2. Open `index.html` in your browser.

## What I learned

- Manipulating the DOM with JavaScript
- Saving and loading data with `localStorage`
- Building a responsive layout with CSS
- Using Git and GitHub, and deploying with GitHub Pages
